# Model Routing

Last checked: 2026-07-12.

1. 高リスク、外部送信、投稿、merge/push、削除、購入、認証変更は `human` / `AWAITING_APPROVAL`。
2. 分類、タグ、抽出、形式変換、短い要約は `local_llm` / `low`。
3. Work指定は `work_manual`。ブラウザ自動操作は行わず作業パケットを生成。
4. それ以外、特にコード変更は `codex`。
5. ユーザー指定Worker/モデル/思考レベルを優先し、利用不能なら勝手に代替せず失敗理由を返す。

Codexモデルと対応思考レベルは `codex debug models` から取得します。2026-07-12のローカル環境では `gpt-5.5`、`gpt-5.4`、`gpt-5.4-mini`、`codex-auto-review` が検出されました。LM Studioは `/v1/models` を使用します。

品質評価は、事実性30、目的達成20、構成15、独自性15、媒体適合10、読みやすさ10です。合格点は既定85。75-84は同モデル再改善、60-74は思考レベルを上げ、59以下は入力待ちへ止めます。最大試行回数を超えて再実行しません。
